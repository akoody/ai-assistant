# Аудит рефакторинга

Первый этап выполнен 10 ноября 2026 года, второй — 11 ноября. Развёртывание и изменение рабочих данных не выполнялись.

## Изменения

- Удалена неиспользуемая вложенная копия планировщика из `ai-slots/src/src`, её скрипты и промпты. Рабочий вход slots использует `src/index.js` и `src/services`.
- Планировщик разделён на этапы диалога, сценарии ответов и модули подбора событий. Основной обработчик раньше занимал 17 123 строки, сервис предложений 9 030 строк. Публичные пути импортов сохранены фасадами.
- Извлечение слотов и инструмент Kassir разделены на очередь, политики проверки, маршрутизацию, HTTP-клиент и предметные операции.
- Веб-сервер разделён на приложение, запуск, конфигурацию, авторизацию, маршруты, аналитику и хранение. Создание приложения не открывает порт и не подключается к MongoDB.
- Дублированное управление MongoDB-подключениями заменено общей фабрикой с внедрением клиента. Параллельные запросы ожидают одно подключение; ошибка очищает соединение и позволяет повторить попытку.
- Удалены неиспользуемые функции, прокси-зависимости, лишняя зависимость dotenv, пустой тестовый файл, отдельный lock-файл без package.json и сохранённый ответ API. Дампы API теперь исключены из Git.
- Добавлены общие команды проверки и тестирования, шаблон окружения и защищённая упаковка текущего дерева. Лаунчер управляет прямыми Node-процессами и завершает группу при отказе сервиса.

## Секреты

`.env` не отслеживается Git. Значения текущих секретов из `.env` не найдены в исходниках. Закомментированные учётные данные прокси и вывод API-ключей/части токена удалены. Внутренние рабочие ключи и ключи провайдеров читаются из окружения; прежние настройки из БД поддерживаются для совместимости.

Новый архив проверен по списку файлов: включён `.env.example`, реальные `.env*` отсутствуют. В девяти существовавших локальных ZIP-архивах в `dist/` обнаружен `.env`. Старые архивы сохранены. Их нельзя распространять без очистки; ранее сохранённые в коде, истории Git или архивах секреты нужно заменить у соответствующих провайдеров. Удаление секрета из текущего файла не отменяет прежнее раскрытие.

## Второй этап: ревью и доработка (11 ноября 2026)

### Найденные ошибки

- **Выдача мероприятий не работала.** После разделения `offerService` динамический импорт `./statusService.js` в `offers/offerOrchestrator.js` указывал на несуществующий файл. Каждый поиск с найденными событиями и `requestId` (его передаёт любой запрос из чата) заканчивался ответом «не удалось найти подходящие мероприятия». Исправлено; `check` теперь проверяет и динамические импорты, а сквозной тест падает при возврате ошибки.
- **`\b` рядом с кириллицей.** В JavaScript `\b` считает словом только `[A-Za-z0-9_]`, поэтому `/\bрок/u` не находит даже `"рок"`. 368 таких границ в 186 регулярных выражениях (31 файл) молча не срабатывали: эвристики здоровья, валидации уточнений, жалоб, отзывов, идентичности ассистента. Заменены эквивалентом с поддержкой кириллицы (`scripts/fix-cyrillic-word-boundaries.cjs`); `check` запрещает новые случаи.
- «Мне не нравится твой тон» не распознавалось как критика ассистента: опечатка `нрав(?:ит|ятся)` вместо `нрав(?:ится|ятся)`.
- Валидатор ответов на критику отвергал 10 из 16 собственных шаблонов, а значит, и LLM-ответы в том же стиле («Мне жаль, …», «Что бы вы хотели посмотреть?»).
- Ответ на жалобу о самочувствии склеивал абзацы: `replace(/\s{2,}/g, ' ')` (ab202d7) срабатывал раньше обработки переносов строк.
- Запрос «должен приехать популярный артист, не помню кто» уходил в общий корень каталога вместо популярной подборки города.
- Продолжение запроса про цирк («хочу на цирк» после того, как цирк уже искали) считалось сменой категории и сбрасывало дату.
- «Стендап» не распознавался как название категории («стэндап» в таксономии).
- `hasPositiveFeedback` возвращал `null` вместо `false`; основной маршрут поиска имел разную форму параметров (`keyword: ''` или без него) в зависимости от числа жанров.

### Тесты

Бисекция по 55 коммитам показала, что 22 из 28 падавших тестов не проходили ни разу: их закоммитили красными в b63cb77. Ещё 5 сломались в 6c2f711 и ab202d7. Каждый случай разобран по существу:

- исправлен код, где тест описывал задуманное поведение (ошибки выше);
- обновлён тест, где поведение изменили сознательно: эвристический поисковый запрос в планировщике отключён с комментарием в коде; шаблоны извинений переписаны в 6c2f711; «спектакль» ведёт на жанровый маршрут; пять случайных жанров из шести вместо фиксированного списка;
- исправлен тест, где он был ошибочным: асинхронная функция вызывалась без `await`, ожидалась несуществующая кнопка «Стендап», завершающий слэш в slug.

Добавлены: сквозной тест `POST /api/chat/message`, тесты контрактов обработчиков `replies/`, проверка шаблонов против собственного валидатора, тесты `shared/serviceRuntime.js`. Сеть в модульных тестах отключена: раньше часть тестов обращалась к запущенному локально ai-gateway.

Итог: **485 тестов, 0 падений** (shared 16, gateway 3, planner 337, slots 113, tools 11, web 5). Конвейер проверен в чистой копии без `.env` и `node_modules`; все сервисы и лаунчер запущены на локальной MongoDB с временной базой, остановка по сигналу проходит с кодом 0.

### Инфраструктура и архитектура

- CI на GitHub Actions: `check` и `test` на каждый pull request и пуш в `main`.
- Prettier применён ко всему проекту; `.gitattributes` и `.editorconfig` фиксируют LF и UTF-8. ESLint запрещает неиспользуемые переменные; 29 случаев устранены (включая мёртвую закомментированную фичу в `generateOffers`).
- Ветви-ответы `routeRequest` вынесены в `response/replies/` с явным контрактом; `routeRequest` сократился с 1639 до ~1100 строк.
- Контекст конвейера разделён по этапам вместо одного плоского объекта; сигнатура этапа показывает источник каждого входа.
- Общий каркас сервисов `shared/serviceRuntime.js`; у всех сервисов `src/app.js` отделён от запуска. Остановка теперь закрывает HTTP-сервер и завершает открытые запросы, а не вызывает `process.exit` сразу.
- Удалены устаревшие `test-runner.js` в gateway и slots, черновик `ai-tools/test-script.js`, пустые каталоги тестов.

## Границы проверки

Внешние Kassir/LLM-запросы и сценарии с рабочей БД не проверялись; сквозной и регрессионные тесты используют фикстуры.

**Исправление `\b` меняет поведение.** 186 регулярных выражений, которые раньше никогда не срабатывали, теперь работают так, как их написали. Ни один из 485 тестов от этого не сломался, а 5 починились, но эвристики, не покрытые тестами, могут начать влиять на диалоги. Перед релизом нужен прогон типовых диалогов на отдельном стенде.

Публичный трекинг `/api/analytics/track` по-прежнему принимает `userId/clientId` и может обновлять их связь; модель доверия требует отдельного изменения контракта виджета.

Дальнейшие направления: эвристики и словари в файлах по 1000–1700 строк (`searchDefinitions.js`, `searchRouting.js`, `intentHeuristics.js`), часть этапов всё ещё принимает 30–50 входов, браузерные файлы виджета не разделены, типы (TypeScript или JSDoc) не введены.
